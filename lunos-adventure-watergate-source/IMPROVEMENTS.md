# 改修版 変更内容・確認結果

この改修版は、オリジナルの物語・画像・音声を維持したまま、遊びやすさと進行保存を改善したものです。

## 表示・操作

- 謎解き：11×9の各マスに線を表示。青枠が次に移動可能なマス、金枠が作用できる仕掛け、赤い×が通行不可。燭台の間では、未照明の床を暗くして×の乱立を避ける。足元の輪でルノの位置も表示。
- 戦闘：7×7のマス目、移動可能範囲、移動不可マスを明示し、背景を不透明にする。
- ノベル：洞窟背景の壁・床にベース色を設け、境目に影と縁を入れる。岩・水門付近の小物の位置と大きさを調整する。
- キャラクターや小物：素材アトラスの透過アルファを維持した合成とし、Canvasに不透明な地面を敷いて背景の白抜けを防ぐ。
- 水路：スイッチを踏むまでは地面の下に隠し、淡いきらめきだけを目印にする。選択肢は水門の部屋の導入時に表示。
- 会話：「▶▶ 会話スキップ」ボタンを追加。選択肢の場面では自動停止し、プレイヤーの選択を勝手に飛ばさない。

## ゲームルール・継続

- セーブ形式 v2：区画開始時に加えて、謎解きの操作後／ターン進行・戦闘コマンド操作後に、盤面・行動履歴・戦闘状態・HP・不安を保存する。タイトル画面の「つづきから」で盤面の途中から復帰可能。
- 復帰時に、区画開始時から必要な既読シーンだけを高速再生し、既に選んだ選択肢を自動再現して二重加算を防ぐ。セーブ時点の重要フラグとHPを、盤面へ入る直前に復元する。
- セーブ先：ブラウザの localStorage。別ブラウザやシークレットモード間で共有されない。保存が無効な環境でもゲーム自体は動作する。
- HP：戦闘中のHP・不安を本体に同期。HPを0〜最大値に収め、戦闘開始時の誤った「0 → 1」補正と、体当たり反動による下限処理を修正。
- 燭台：旧ふつうの盤面をかんたんに移し、ふつうに新しい8燭台ルート・連鎖を追加。むずかしいは維持。
- 「呼びかける」：発動ターンを含めて2回のフラメトの行動で、敵の追跡よりルノへの接近を優先する。

## テスト

- `node test/levels_check.js`：全難易度・全区画の謎解きが解けることを確認。
- `node test/rules_node.js`：元の戦闘ルールテストを通過。
- `node test/improvement_check.js`：HPの上下限、呼びかけによる誘導、効果の持続を確認。
- ブラウザ起動テスト：タイトル表示、燭台の盤面、会話スキップ、謎解きオートセーブ／再開、戦闘オートセーブ／再開を確認。実行時のJavaScript例外なし。
- `node test/run_all.js` のブラウザ自動テストは、実行環境に Node の `playwright` パッケージが存在しないため未実施。上記の実ブラウザ検証は Python Playwright を使用。

### 注意事項
一部の映画的なシーン背景は元のドット絵・描画ロジックを残しています。全素材をゼロから描き直したわけではありません。また会話スキップは次の選択肢まで停止する方式で、選択肢そのものを勝手に決めることはありません。

## 2026-11-02　水門の入室イベントと隠し仕掛け・会話表示の改修
- 水門の部屋に入ると、ノベル画面で「フラメトを泳がせる／二人で歩ける道を探す」の二択を表示する。選択後に謎解き画面へ移る。
- 水たまり（Qマス）は背景演出として残すが、踏んでも選択肢は開かない。カルマ・不安は入室時の一度だけ反映する。フラメトを泳がせた際の水中移動アニメーションは、選択後の盤面上で従来どおり再生する。
- スイッチ板は踏んで作動するまで描画しない。床のごく小さな光を手掛かりとし、泳がせた場合はわずかに見つけやすい演出にする。作動後は板を表示。
- 文章横の「原稿」「仮」「S04」などの制作上の出典・管理ラベルを完全に非表示にし、メニューから関連する表示切替を除去する。
- 水門のヒントと会話を、隠された仕掛けの探索に自然につながる表現へ修正。
- Python Playwrightで「選択肢が謎解き前に現れる」「選択後に謎解きへ移る（両ルート）」「Qマスで再発しない」「制作ラベルが空」「途中セーブと再開で選択が重複しない」「JavaScript例外なし」を確認。
